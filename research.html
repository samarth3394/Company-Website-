AI as the New Operating System

Our lab is actively experimenting with a groundbreaking concept: an AI Integrated OS. We are currently prototyping ways to move beyond application-centric environments to build natively intelligent, intent-driven desktop experiences.

Current Lab Focus: Contextual Awareness & Intent-Driven Execution

Hypothesis 1: Deep Contextual Awareness. The traditional operating system has remained blind to the user's workflow. Our team is currently testing experimental models that give the OS deep Contextual Awareness—allowing it to observe and understand user actions across all applications in real-time, providing proactive assistance before a command is explicitly given.

Hypothesis 2: Intent-Driven Orchestration. What if you could simply tell your PC what you want to achieve? We are prototyping an Intent-Driven Execution layer where, instead of a user manually opening apps and transferring data, the OS itself orchestrates the necessary applications autonomously to accomplish the requested goal.

Ongoing Experiment: Agentic Workflows. We are actively integrating background AI agents directly into the system kernel layer. Our current test cases involve agents handling mundane, repetitive tasks by learning user habits, sorting communications, and dynamically preparing the workspace before the workday begins.

The Architecture Shift

Redefining the Stack

For decades, the operating system stack has remained static: Hardware → Kernel → GUI → Applications. The user was the orchestrator.

Our research introduces a native Intelligence Layer sitting between the kernel and the GUI. This layer intercepts user intent, communicates directly with applications via programmatic interfaces, and dynamically generates UI elements when needed.

This fundamentally transforms the computer from a passive tool into an active, intelligent collaborator.
